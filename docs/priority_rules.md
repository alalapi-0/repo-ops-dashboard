# 优先级规则

## 高优先级

- active project
- has clear next action
- related to current AI/product roadmap

## 中优先级

- useful but not urgent
- needs governance cleanup

## 低优先级

- old demo
- unclear value

## 冻结候选

- no clear next action
- no recent update
- duplicated with another repo

## 归档候选

- obsolete
- no README
- no future plan
